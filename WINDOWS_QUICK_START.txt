================================================================================
COMMON ISSUES & FIXES
================================================================================

ISSUE: "ModuleNotFoundError: No module named 'anthropic'"
FIX:
  pip install -r requirements.txt

ISSUE: "python: command not found"
FIX:
  You need to install Python from https://www.python.org/
  Make sure to check "Add Python to PATH" during installation
  Then restart PowerShell

ISSUE: "support_agent_demo.py: No such file"
FIX:
  Make sure you're in the right folder:
    cd C:\Users\User\support_agent\
    ls
  You should see support_agent_demo.py in the list

ISSUE: "Cannot find path because it does not exist"
FIX:
  The folder doesn't exist. Create it first:
    mkdir C:\Users\User\support_agent
